- ☕ **Spring Boot 3 REST API** (Java 21) — Spring Security, JPA, Bean Validation, Springdoc OpenAPI

- ☁️ Integrations: **Cloudinary**, **BulkSMSBD** (OTP), **SMTP email**, **Google sign-in**
